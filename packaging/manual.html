Local OCR

本地手写文字识别

Windows 便携交付版。程序、模型、Python 运行时和默认工作目录都包含在自解压包内；无需安装 Python、uv、Paddle 或其他开发环境。

版本：Portable Delivery 1.0

运行方式：双击自解压 EXE，程序会在 EXE 旁创建 LocalOCR 目录并自动打开本地控制台

隐私：图片在本机处理，不调用云端 OCR API

一、开始使用

  1. 双击交付目录中的自解压 EXE。
  2. 程序会在 EXE 旁创建 LocalOCR 目录并把全部运行文件放入其中，不向用户目录写入缓存。
  3. 浏览器打开本地控制台后，拖放图片或点击“选择文件”。
  4. 选择设备：推荐“自动”。有 NVIDIA GPU 时使用 GPU，没有时自动使用 CPU。
  5. 确认输入目录和输出目录，点击“开始本地识别”。

二、设备与迁移

有 NVIDIA GPU

自动模式会检测第一个可用 CUDA 设备并使用 GPU。当前项目在 RTX 4060 上已验证。

没有 NVIDIA GPU

同一套交付包会检测不到 CUDA 设备并切换到 CPU。无需重新安装依赖。

请使用 64 位 Windows。GPU 加速需要兼容的 NVIDIA 驱动；驱动不可用时自动模式仍可使用 CPU。

三、网页设置

  • 图片：支持 PNG、JPG、JPEG，可一次添加多张。
  • 输入目录：可使用程序目录内的 input，也可以通过“选择”按钮选取其他磁盘目录。
  • 设备：自动、CPU、GPU 0。
  • CPU 线程数：0 表示程序使用系统默认线程数。
  • 预处理：文档方向校正、透视矫正、文字行方向识别。
  • 输出目录：默认是程序目录内的 output，需要其他位置时直接填写目录路径。
  • 保存 JSON：默认关闭。打开后会额外保存每张图片的详细 JSON。

四、输出文件

  • 图片名.txt：识别文本。
  • 图片名_ocr_res_img.png：带识别标注的图片。
  • summary.csv：批次汇总。
  • 图片名.json：开启“保存 JSON”后生成。

五、安全与数据位置

控制台只监听 127.0.0.1，不会监听局域网地址。API 使用启动时生成的随机访问令牌，并检查本机来源。未授权请求不能调用识别、上传、目录选择或文件下载接口。

程序默认缓存、上传临时文件和模型都在解压目录内。输入和输出可以由用户明确选择到其他目录；程序不会扫描或读取未选择的外部目录。

六、问题排查

  • 页面打不开：确认自解压后的程序仍在运行，并重启自解压 EXE。
  • GPU 不可用：在网页选择“自动”，程序会使用 CPU。
  • 识别速度较慢：减少预处理选项，或使用 GPU 设备。
  • 空间不足：模型和运行时体积较大，请选择至少 8 GB 可用空间的解压目录。
